# LibreDSP

**LibreDSP** is a DSP library (written in Rust with WASM bindings) for designing digital filters, hybrid simulation, and more.
The project also contains the project **LibreDSP Workbench** which is a web app (built with Typescript and React) providing graphical user interface for the library. 

To try LibreDSP Workbench, visit: [LibreDSP.github.io](https://LibreDSP.Github.io)

The source code of 'LibreDSP' is available on [github.com/libredsp/libredsp](https://github.com/libredsp/libredsp).
The library is also hosted on crates.io and its WASM build is on NPM. 

You may also find the the source code for LibreDSP Workbench [here](https://github.com/libredsp/workbench).
